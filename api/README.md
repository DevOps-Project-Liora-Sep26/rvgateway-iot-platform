# RvGateway Web API

FastAPI backend for the RvGateway IoT Monitoring Platform.

The API provides user authentication, profile management and gateway management. MariaDB is used for application data, while InfluxDB is used for gateway telemetry and time-series data.

```text
    └── gateways.py
```

## Architecture

The backend is divided into separate modules for application configuration, API routing, authentication, data models and database access.

### `main.py`

Application entry point.

Responsibilities:

- FastAPI application initialization
- CORS configuration
- Router registration

The application is started using the `app` object defined in this module.

### `auth.py`

Shared authentication and session handling.

Responsibilities:

- Password hashing using Argon2
- Session configuration
- Session cookie handling
- Authentication of the current user

Authentication functionality that is required by multiple API routes is kept in this module.

### `models.py`

Contains the Pydantic request and response models used by the REST API.

Examples include:

- Login requests
- Registration requests
- Password change requests
- Gateway requests
- API response models

These models define and validate the data exchanged between the API and its clients.

### `db_mariadb.py`

Provides access to the MariaDB database.

MariaDB stores application-related relational data such as:

- Users
- Sessions
- Gateways
- User-to-gateway assignments

### `db_influxdb.py`

Provides access to InfluxDB.

InfluxDB stores time-series data generated by the gateways, including telemetry and measurements.

The module also provides helper functions for querying gateway data.

## Routers

The `routers/` directory contains the REST API endpoints grouped by functionality.

### `routers/authentication.py`

Authentication endpoints.

Includes:

- User registration
- Login
- Logout

### `routers/profile.py`

User profile endpoints.

Includes:

- Get current user
- Change password
- Delete profile

### `routers/gateways.py`

Gateway management endpoints.

Includes:

- Add a gateway to a user
- Further gateway management endpoints

### `routers/__init__.py`

Marks the `routers` directory as a Python package.

This allows the individual router modules to be imported by the application.


The router handles the HTTP request and uses the required authentication, database and data model modules.

## Running the API

Activate the Python virtual environment:

```bash
source .venv/bin/activate
```

Start the FastAPI development server:

```bash
uvicorn main:app --reload
```

The API is available at:

```text
http://localhost:8000
```

Interactive API documentation is available at:

```text
http://localhost:8000/docs
```

Alternative ReDoc documentation is available at:

```text
http://localhost:8000/redoc
```
