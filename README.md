# RvGateway IoT Platform

## Description

**Design and Operation of a Scalable, Dynamic and Resilient IoT Platform**

This project is based on an existing and operational [ESP32-based IoT Edge Device](https://github.com/degersti/rv-monitoring-gateway)
and backend prototype. The gateway collects sensor and system data and transmits them via MQTT to the backend (initial situation).

The work within this project will focus on the infrastructure and data flow required to provide this data through a simple
web application. According to the project requirements, the focus is on the deployment and operation of
the required microservices. Backend logic development and application design are only part of the scope as
far as they are needed for the core functionalities.
